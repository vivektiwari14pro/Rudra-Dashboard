# Rudra Dashboard

Responsive location-wise transporter trip dashboard for Rudraksha Enterprises.

## Features
- Location-wise trips: loading and unloading locations
- Transporter-wise and vehicle-wise monitoring
- KPI cards for trips, vehicles, quantities, freight and net payable
- Date, location, transporter and status filters
- Trip details including gate pass, challan, loading/unloading quantity, advances and deductions
- Loading vs unloading shortage calculation
- CSV import and filtered CSV export
- Mobile-friendly layout

Open `index.html` directly in a browser or deploy the repository with GitHub Pages.

### CSV columns
tripId,date,vehicleNo,transporter,loadingLocation,unloadingLocation,gatePassNo,challanNo,loadingQty,unloadingQty,freight,cashAdvance,bankAdvance,deductions,status
